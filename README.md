# Python-Java Chatbot

A simple chatbot that answers questions about Python and Java programming using a collection of 500 questions and answers.

## Features
- 250 Python questions and 250 Java questions.
- Gives answers from its saved question-answer collection.
- Answers only Python and Java-related questions.
- Does not answer unrelated questions.
- Works without external AI APIs.
- Includes automatic tests.

## Technologies Used
- Python
- JSON
- TF-IDF
- BM25

## Installation

```bash
git clone https://github.com/singhmohit01336-design/Python-Java-Dataset-Chatbot.git
cd Python-Java-Dataset-Chatbot
pip install -r requirements.txt
```

## Run the Chatbot

```bash
python3 main.py
```

## Run Tests

```bash
python3 tests/test_chatbot.py
```

## Dataset
- Python: 250 Questions & Answers
- Java: 250 Questions & Answers
- Total: 500 Questions & Answers
